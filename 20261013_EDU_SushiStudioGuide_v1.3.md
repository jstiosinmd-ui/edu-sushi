# SUSHI Clerks Comprehensive Exam Reviewer

---

Open [SUSHI v1.3](20261013_EDU_SushiClerksExamStudio_v1.3.html) in Chrome, Edge, or another browser that runs local HTML applications. The HTML contains all questions, artwork, fonts, and PDF software and works offline. Extract the ZIP before opening it. Ordinary file previewers may not run JavaScript.

## Your study menu

| Mode | What it does |
|---|---|
| **Fresh Catch 10** | Ten random unanswered questions from one or more chosen subjects, with feedback after checking an answer. |
| **Maki Mentor** | Guided practice with a chosen count, subject, topic, difficulty, and question pool. |
| **Wasabi Rush** | Timed practice. Answers remain editable and explanations stay hidden until you finish or time expires. |
| **Bento Builder** | A custom exam paper, blank answer sheet, and matching answer key, downloadable as PDFs. |
| **Roll Call** | The searchable question library, including explanations, source notes, and bookmarks. |

The Counter is the home page. Open a character card to choose a mode. Practice settings can also switch among the three on-screen practice modes. Starting a different set asks before replacing an unfinished one.

## Fresh Catch 10

1. Select **Fresh Catch 10** from the Counter or the Practice mode selector.
2. Check any combination of Internal Medicine, OB-GYN, Pediatrics, and Surgery. The counts show the unanswered questions available in each subject.
3. Tap **Serve my Fresh Catch 10**. It draws exactly ten questions from the selected pool. All topics and difficulties are eligible; the draw does not guarantee equal subject counts.
4. Choose an option, then tap **Check answer** to see the explanation. Continue through the set and select **Finish set** for your results.

Selecting an answer in any practice mode permanently adds that question to the local Fresh Catch history, even if the answer is incorrect, is later changed, is never checked, or the active set is replaced. Reloading, switching subjects, or switching modes does not make it fresh again. Viewing a question without selecting an answer does not consume it. The duplicate Surgery stem is also excluded if its companion item has been answered.

If fewer than ten eligible questions remain, the button is disabled and the available count is shown. Add a subject or switch to Maki Mentor for a smaller set using the **Not yet reviewed** pool. That pool means no checked or submitted answer yet, so it can include unchecked selections that Fresh Catch already excludes.

Fresh Catch is untimed. Answer history is saved on this browser and device. Resetting progress clears that history; restoring a backup replaces it with the history in that backup.

## Your sushi passport

| Tier | Distinct questions completed |
|---|---:|
| **Rice Rookie** | Starting tier |
| **Maki Explorer** | 10 |
| **Nigiri Navigator** | 50 |
| **Temaki Trailblazer** | 150 |
| **Wasabi Warrior** | 350 |
| **Omakase Legend** | 700 |

Check an answer in Maki Mentor or Fresh Catch, or submit a set in any practice mode, to complete a question. Correct and incorrect submissions both count as completed. Unanswered items do not count toward a tier. Repeating a question never increases the distinct-question count. Existing submitted progress earns its corresponding tier immediately.

The top sticky bar shows your current tier, completion count, and progress toward the next milestone on every screen. Tap the tier badge to open **Your sushi passport** and see all six achievement tiers, your current tier, and the number of questions needed for the next one. Close the passport or press Escape to return to the same view, question, and scroll position. On phones, scroll inside the passport to see the whole collection; its Close button stays visible. Your tier updates after checking answers, submitting a set, restoring a backup, or resetting progress. These milestones track practice activity; latest-answer accuracy is displayed separately. After the final tier, the passport shows completion out of all 1,047 question IDs.

## Practice and exam PDFs

Maki Mentor and Wasabi Rush retain the subject, topic, difficulty, new, missed, and bookmarked filters. A checked guided-practice answer is locked. Timed answers remain editable until submission. Unanswered questions count as incorrect in the set score. The active session resumes after a reload; the Wasabi Rush deadline continues while the tab is hidden or closed.

In Bento Builder, enter a title, date, count, duration, subjects, and difficulty. Optionally select topics. Balancing distributes questions across the selected subjects or topics according to available capacity. A request that cannot be satisfied reports the shortage. The same seed, settings, and question bank reproduce the same draw.

Prepare the exam PDF and answer key, then tap each save link. On phones, use the PDF viewer's Save or Share control if a preview opens. Choose explanations and sources for a detailed key, or turn that option off for a compact key. Changing an exam setting clears the previous draw and links. Save the PDFs or JSON record before closing; the PDF draw is not saved automatically. JSON exam-record import is not implemented.

All application views and every generated PDF page carry **Jon Bryan S. Tiosin, MD** and **(c) jstiosin 2026**. The question paper includes a blank answer sheet and preserves original option order. The HTML includes answers; share the question-paper PDF when examinees should receive only the exam.

## Bring your previous progress

Before leaving an earlier version, use **Sources and progress → Download progress backup**. In v1.3, open **Sources and progress → Restore a SUSHI backup** and select that file. The prior HTML is retained at its original path so it can still read progress associated with that path.

The app accepts v1.0, v1.1, v1.2, and v1.3 backups for this question bank. Imported v1.0 submitted answers become Fresh Catch history and unlock tiers. Only answers actually saved by the earlier version can be recovered; abandoned unchecked choices from old sessions were not recorded by v1.0. An existing saved active session's selections are migrated when available in the same browser storage.

New backups preserve completed answers, answer attempts, bookmarks, Fresh Catch history, and selected Fresh Catch subjects. Restoring replaces current progress and clears the active session. Download a backup before moving the HTML, changing browsers, or clearing browser data. Local-file storage can depend on the exact file path. If storage is unavailable, export a backup before closing. Use one active browser tab for studying to avoid competing local saves.

## Questions and artwork

The same 1,047 released questions are retained: Internal Medicine 303, OB-GYN 194, Pediatrics 239, and Surgery 311. They cover 67 subject-topic combinations, with 531 Easy, 489 Average, and 27 Difficult items. All 33 original CSV columns, stems, options, keys, rationales, explanations, learning objectives, and citations are preserved. This release changes software and artwork, with no new clinical content review.

Two Surgery entries share a stem but have different alternatives. Both remain in Roll Call; a generated set includes at most one of them. Fresh Catch also excludes the companion stem after either entry has been answered.

The four mode characters accompany the SUSHI logo and banner: Maki with a book, Temaki with a star card, the Wasabi runner with a stopwatch, and the Omakase chef with a trophy and clipboard. All are embedded in the HTML and provided separately in `assets/`. They were generated with the built-in image-generation tool. The four specialty characters introduced in v1.2 remain included. The mode-character prompt record and subject-character record retain the exact generation prompts. The release manifest lists asset hashes.
